# 任务 K1：定义并校验公共 Contracts

> 本文只维护该任务的实施与验收详情。状态、优先级、依赖、执行顺序和阻塞以 [Dashboard](../Dashboard.md) 为唯一权威来源。

## 背景与目标

使 Core、Executor、Packager 在同一组版本化类型、JSON Schema 与测试 fixture 上通信。

## 执行上下文

- **权威需求**：[设计文档](../../../../dev-harness-runtime-design.md) §8–14、§18、§23、§26、§30、§45 K1；[资料评估](../Readiness.md)。
- **公共实施依据**：[CONTRACTS](../../CONTRACTS.md)、[R0 决策](../../decisions/runtime-contracts.md)、[DSH 迁移边界](../../DSH_MIGRATION.md)。
- **代码入口**：从下列影响文件进入。初始化时目标项目为空，所列实现与测试路径均为建议新建路径，不能当作已有代码。
- **相关测试**：合法和非法 JSON fixture；版本兼容矩阵；共享 Executor Contract Test 工厂。
- **必须保持的不变量**：版本变化显式管理；结果必须绑定当前任务与执行尝试；授权不可由 Worker 扩大。


## 范围

- **包含**：TaskExecutionRequest / Result、VerificationEvidence、Authorization、Snapshot、RunState、Capabilities、Packager 输入输出及 Registry 契约。
- **不包含**：宿主专属字段进入公共业务接口；通过类型断言跳过运行时校验。

1. 重读 Dashboard 与本任务，检查来源是否漂移；从资料评估对应条目和已形成的决策记录确认输入。

## 已确认决策

- 项目名 `dev-harness-runtime`，CLI 全部使用 `dhr`。
- 状态根目录统一为 `$(git rev-parse --git-path dev-harness-runtime)/runs/`；具体布局以设计 §10 为准。
- 版本变化显式管理；结果必须绑定当前任务与执行尝试；授权不可由 Worker 扩大。

## 未知项与停止条件

- **已知风险**：来源升级、接口不完整或环境不足可能使验收不可复现；不能将设计示例或历史通过记录当作本次运行证据。
- **未决问题**：公共字段、身份绑定、状态转移、结果证据和 Packager 数据语义已在 [CONTRACTS](../../CONTRACTS.md) 定义；本任务负责将其转为类型、Schema 与正反 fixture。
- **停止条件**：需要扩大范围、改变公共语义或验收、使用无证据宿主能力，或发现 Git / Planning 外部漂移时停止实现，回到 Dashboard 对齐。
