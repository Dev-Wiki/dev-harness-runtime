# 任务 K10-G：Portable Agent Plugin 打包

> 本文为已完成任务的归档快照。当前状态和工作顺序以 [Dashboard](../../Dashboard.md) 为唯一权威来源。

## 背景与目标

交付平台中立的共享 Skill 子集，明确其安装能力与 Runtime 执行能力的边界。

## 执行上下文

- **权威需求**：[设计文档](../../../design/runtime-design.md) §20、§25、§27、§39、§41；[资料评估](../../Readiness.md)。

- **相关测试**：Agent Plugin 官方 schema fixture、生成树比较、未配置 Adapter 时调用 run 的说明或拒绝路径。
- **必须保持的不变量**：只维护共享 Skill 源码；自动运行必须由可用 Runtime Adapter 提供能力。

## 已确认决策

- 项目名 `dev-harness-runtime`，CLI 全部使用 `dhr`。
- 状态根目录统一为 `$(git rev-parse --git-path dev-harness-runtime)/runs/`；具体布局以设计 §10 为准。
- 只维护共享 Skill 源码；自动运行必须由可用 Runtime Adapter 提供能力。

## 未知项与停止条件

- **已知风险**：来源升级、接口不完整或环境不足可能使验收不可复现；不能将设计示例或历史通过记录当作本次运行证据。
- **未决问题**：严格的本仓最小产物已按官方 1.0.0 manifest 字段校验；具体宿主的 tolerant loader 和安装 smoke 不属于平台中立 ZIP 的自动执行能力证明。对外分发仍受许可门禁约束。
- **停止条件**：需要扩大范围、改变公共语义或验收、使用无证据宿主能力，或发现 Git / Planning 外部漂移时停止实现，回到 Dashboard 对齐。

## 完成验收结果

ZIP 六文件内容与共享 Skill 来源一致，版本和摘要纳入统一 release manifest；`agent-plugin` 不注册 RuntimeAdapter，缺少可信宿主执行能力时明确返回 `CAPABILITY_MISSING`。这只证明平台中立包与安全门禁，不代表任何客户端会话已加载或执行 Skill。复现细节见 [K10-G 验证记录](../../../verification/K10-G.md)。
