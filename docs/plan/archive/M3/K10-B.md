# 任务 K10-B：共享生成、校验与打包流水线

> 本文为已完成任务的归档快照。当前计划状态与执行顺序以 [Dashboard](../../Dashboard.md) 为唯一权威来源。

## 背景与目标

为所有平台提供同一份源输入、生成调度和静态验证基础，先于具体 Packager 落地。

## 执行上下文

- **权威需求**：[设计文档](../../../design/runtime-design.md) §6、§18、§24、§27–31；[资料评估](../../Readiness.md)。
- **公共实施依据**：[CONTRACTS](../../../CONTRACTS.md)、[R0 决策](../../../decisions/runtime-contracts.md)、[DSH 迁移边界](../../../DSH_MIGRATION.md)。
- **代码入口**：从下列影响文件进入。初始化时目标项目为空，所列实现与测试路径均为建议新建路径，不能当作已有代码。
- **相关测试**：Fake Packager；两次 clean generate 比较；损坏 manifest、绝对路径、重复 Skill、非法版本等负向 fixture。
- **必须保持的不变量**：.generated/ 与 dist/ 全部生成；版本和元数据来自唯一输入。


## 范围

- **包含**：Build Registry、共享元数据、上游 Skill 来源锁定、有限 transform、generate / validate / pack、golden 比较与可重复构建约定。
- **不包含**：具体平台安装和外部发布；在 transform 中重写编排流程。

- [x] 共享输入到 artifact 的构建依赖图明确，build 与 generate 不递归调用。

## 已确认决策

- 项目名 `dev-harness-runtime`，CLI 全部使用 `dhr`。
- 状态根目录统一为 `$(git rev-parse --git-path dev-harness-runtime)/runs/`；具体布局以设计 §10 为准。
- .generated/ 与 dist/ 全部生成；版本和元数据来自唯一输入。

## 未知项与停止条件

- **已知风险**：来源升级、接口不完整或环境不足可能使验收不可复现；不能将设计示例或历史通过记录当作本次运行证据。
- **未决问题**：来源锁、流水线、版本与可重复构建按 [R0 决策 §5](../../../decisions/runtime-contracts.md#5-版本打包与分发) 实施。缺少许可来源时阻止对外分发；本地产物可验证，不自填许可。
- **停止条件**：需要扩大范围、改变公共语义或验收、使用无证据宿主能力，或发现 Git / Planning 外部漂移时停止实现，回到 Dashboard 对齐。

## 完成验收结果

统一 PlatformRegistry 已接通 CLI 的运行与 build / validate / pack 入口；可信 BuildPipeline 对来源、版本、共享元数据、生成目录及归档产物逐阶段核验。Fake Packager 从锁定输入重复生成相同内容，静态验证覆盖设计 §29 全部项目，ZIP / USTAR gzip 的固定时间与 golden 已通过独立解包检查。每个阶段独立运行，不隐式调用前一阶段。真实平台 Packager、宿主安装与外部分发许可仍由后续执行包承担。
