这些事实只证明新会话事件与合成结构化输出入口可用，并提供 `workspace-write` 在本机不能约束同级临时路径的反例。尚未证明逐 Task 文件写入白名单、外部动作禁止、取消后整个 Worker 树静止、结果与 Core 请求身份绑定、完成结果及恢复使用不同 Session。不能凭 CLI help 或上述合成会话推定满足 `authorizationEnforced:true`。因此 `adapter-codex` 仍不注册 TaskExecutor；`dhr run --adapter codex` 继续明确拒绝，而不会退化为父会话手工执行。MVP 三 Task 自动验收尚未运行。
