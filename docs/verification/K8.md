## 已纠正的宿主加载问题

早期只从 OpenCode 1.18.31 `/config` 看见插件路径，却没有检查日志；复核发现旧入口实际上报 `must default export an object with server()`。OpenCode 2.0.15 也拒绝了缺少 `id`、`setup()` 的旧入口。当前同一插件默认导出 `{ id, server, setup }`，保留命名函数兼容更早加载器；结构依据 [OpenCode 官方双版本插件说明](https://opencode.ai/v2/docs/build/plugins#support-v1)。1.18.31 的本次 run 无插件加载错误；2.0.15 的 `/api/plugin` 报 `dev-harness` 为 `active`，两个版本都发现三个 Skill。
